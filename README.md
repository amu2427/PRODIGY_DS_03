# PRODIGY_DS_03
🏦 Decision Tree Classifier – Bank Marketing Dataset
📌 Project Overview

This project was developed as part of my internship task.
The objective is to build a Decision Tree Classifier to predict whether a customer will subscribe to a bank product based on demographic and behavioral data.

The dataset used is the Bank Marketing Dataset from the UCI Machine Learning Repository.

🎯 Problem Statement

To predict whether a customer will purchase a product or subscribe to a service (Yes/No) using supervised machine learning techniques.

📊 Dataset Description

The dataset contains customer information including:

Age

Job

Marital status

Education

Account balance

Housing & loan status

Contact type

Campaign details

Duration of call

Previous interactions

Target variable (y) – Subscription (Yes/No)

🛠️ Technologies Used

Python

Pandas

NumPy

Matplotlib

Scikit-learn

Jupyter Notebook

🔍 Project Workflow
1️⃣ Data Preprocessing

Loaded dataset

Checked for missing values

Encoded categorical variables using Label Encoding

2️⃣ Exploratory Data Analysis (EDA)

Visualized target variable distribution using bar graphs

Analyzed categorical features vs subscription

Plotted histograms for numerical features

3️⃣ Model Building

Split dataset into training and testing sets

Built a Decision Tree Classifier

Limited tree depth to prevent overfitting

4️⃣ Model Evaluation

Accuracy Score

Confusion Matrix

Classification Report

5️⃣ Feature Importance Analysis

Visualized feature importance using bar graphs

Identified most influential factors affecting customer subscription

📈 Results

The model successfully classified customer subscription behavior.

Campaign-related features and call duration had strong influence.

The Decision Tree provided clear and interpretable decision rules.
